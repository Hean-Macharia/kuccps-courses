Activation Instructions
When to use manual activation:
  • User paid but didn't receive results
  • Payment confirmation failed
  • System error during payment processing
  • User has valid M-Pesa receipt but no access
  • User's payment record is corrupted
What happens after activation:
  • Old payment record is DELETED
  • New activation record is created
  • Original receipt is stored permanently
  • User can bypass payment check
  • User gets results immediately
