# Search intent and page map

Updated: 2026-11-27

## Evidence and limitations

This is a search-intent map, not a keyword-volume report. No Google Search Console query export, Google Ads Keyword Planner account, or Bing Webmaster query report was available during preparation. Search volumes, difficulty, ranking positions, and traffic estimates are therefore **not measured**. Avoid describing any target as high-volume or low-competition until a dated data export supports that claim.

The topic map reflects the site's real pages and common student tasks. Official KUCCPS guidance should be used for placement procedure, current programme requirements, and cluster-point explanations. Courses Checker is independent and does not make official placement decisions.

## Refresh with first-party query data

1. Export Search Console **Performance → Search results** for the last 3 months and 12 months (queries, pages, clicks, impressions, CTR, average position).
2. Export Bing Webmaster search performance for the same periods where available.
3. Keep brand/navigation queries separate from informational and course-category intent.
4. Map each query cluster to one primary URL. Investigate queries with impressions but weak CTR by reviewing the matching title and snippet; investigate overlapping pages before creating new URLs.
5. Store dated exports and update this map with measured values, country/device filters, and the export date. Do not promise rankings or treat impressions as search volume.

## Editorial guardrails

- Write for students and parents first; use relevant wording naturally in the title, H1, opening, and useful section headings.
- No hidden keyword blocks, repeated city/course lists, fabricated course examples, or unsupported grade/cut-off claims.
- Cite official KUCCPS, institution, or government sources for time-sensitive requirements and application instructions; show when the facts were checked.
- Add structured data only when it describes visible, accurate page content and meets current search-engine policies.
